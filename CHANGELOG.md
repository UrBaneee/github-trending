# Changelog

## 2.0.0 — 2026-11-14

### Added

- Guided Study Mode triggered by `study owner/repo` or equivalent requests.
- A seven-stage learning protocol covering business reality, system mapping,
  code-path tracing, mechanism boundaries, capability testing, contribution,
  production readiness, and teach-back.
- Persistent per-repo learning trails under `wiki/studies/`.
- Evidence labels separating repository facts, author claims, and inference.
- Repo-specific Study hooks in daily digests.
- Study-wiki maintenance checks.

### Changed

- Reframed the skill from a daily summarizer into a connected discovery and
  project-learning companion.
- Clarified that README claims are not implementation evidence until Study Mode
  inspects source code or runtime artifacts.
- Updated README and skill documentation for the 2.0 workflow.

### Preserved

- Existing `/trending` discovery workflow.
- Persistent per-repo trend history.
- stdout, Telegram, and email delivery.
- English, Chinese, and bilingual output modes.
